# MD Anderson Cancer Institute: Cancer Diagnosis Using Artificial Neural Networks (ANNs)

## 📌 Project Overview
This repository contains my data science and deep learning project focused on building an Artificial Neural Network (ANN) to classify tumor diagnoses (benign vs. malignant) using the MD Anderson Cancer Institute diagnostic dataset. The project implements a complete end-to-end machine learning pipeline—from exploratory data analysis and feature scaling to deep neural network training, evaluation, and visualization.

---

## 🛠️ Tech Stack & Dependencies
I built and executed this project in an interactive **Jupyter Notebook** environment using the following Python libraries:
* **Python** (Core language)
* **Pandas & NumPy** (Data manipulation and analysis)
* **Scikit-Learn** (Data splitting, feature scaling, and evaluation metrics)
* **TensorFlow / Keras** (Deep learning model building and training)
* **Matplotlib & Seaborn** (Exploratory data visualizations, correlation heatmaps, and training curves)
